# Compatibility

Requires Node.js 22 or later and Blogger themes version 2. Builds validate XML, widget settings and supported expression syntax. Local previews emulate Blogger and are not its native compiler. Back up your current theme, restore on a test blog, save in Edit HTML, and test home, post, Page, search, Label, archive, 404, comments, mobile navigation and editing before deployment. Search visibility, indexing and AI citations require separate hosted checks.
